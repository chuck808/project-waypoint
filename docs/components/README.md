# Component Documentation

This folder documents reusable UI components for Project Waypoint.

The component system should follow BP015 – Experience & Design System.

## Component Principles

Every reusable component should be:

- accessible
- documented
- testable
- reusable
- visually consistent
- calm and unobtrusive

## Initial Component Groups

### Mobile

- TrailCard
- BusinessCard
- PassportStamp
- PrimaryAction
- EmptyState
- ReportBadge

### Shared Web

- DashboardCard
- DataSummary
- StatusBadge
- FormField
- PageHeader
