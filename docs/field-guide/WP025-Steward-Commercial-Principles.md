# WP025 -- Steward Commercial Principles

> **Status:** Proposal\
> **Purpose:** Define how Waypoint can earn revenue without selling
> attention, visibility or personal data.

## Core Principle

Waypoint will charge for management, not visibility.

A legitimate place should be discoverable because it exists, not because
it pays.

## Free Listing

Every legitimate place may have a free listing containing:

-   Name
-   Location
-   Opening hours
-   Contact details
-   Basic description
-   Walker characteristics
-   Dogs welcome
-   Boots welcome
-   Water refill
-   Toilets
-   Accessibility basics

Non-paying places must not be hidden, ranked down, or made artificially
less useful.

## Paid Steward Tools

Paid features should help organisations manage their relationship with
explorers.

Potential £5/month features:

-   Claim listing
-   Update seasonal information
-   Publish events
-   Add temporary notices
-   Offer optional Waypoint perks
-   Receive aggregated visitor analytics
-   Reply to factual corrections
-   Upload better imagery
-   Create QR checkpoints
-   Link to walking itineraries

## Forbidden Commercial Patterns

Waypoint should not sell:

-   Sponsored ranking
-   Paid map prominence
-   Artificial visibility boosts
-   Personal visitor data
-   Behavioural advertising
-   Dark-pattern upgrades
-   Pay-to-remove inaccuracies

## Why This Matters

Trust is a product feature.

If explorers suspect that Waypoint shows places because they paid, the
map becomes less trustworthy.

If explorers know Waypoint shows places because they are relevant, the
map becomes useful infrastructure.

## Steward Language

Prefer:

-   Steward
-   Place Manager
-   Host
-   Verified Steward
-   Official Note
-   Place Insights

Avoid:

-   Advertiser
-   Premium listing
-   Sponsored place
-   Lead generation
-   Growth dashboard

## Analytics

Analytics must be aggregated and privacy-preserving.

Acceptable:

-   Total visits
-   Returning visitors
-   QR scans
-   Popular days
-   Common journey types
-   Anonymous trends

Not acceptable:

-   Individual visitor tracking
-   Personal profiles
-   Cross-place behavioural tracking
-   Sale of location history

## Constitutional Addition

Recommended addition to WP000:

> Waypoint earns revenue by helping people care for places, not by
> selling attention, visibility or personal data.

## MVP Commercial Scope

Version 1 should support:

-   Claim place
-   Edit listing
-   Welcome message
-   QR poster
-   Basic insights
-   Temporary notice

Everything else can wait.
