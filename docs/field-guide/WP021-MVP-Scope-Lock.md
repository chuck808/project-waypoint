# WP021 -- MVP Scope Lock

> **Status:** Product Governance Document

## Purpose

Protect Version 1 from feature creep.

Every proposal must be classified as:

-   MVP
-   Version 2
-   Vision

## Version 1 Goal

Deliver a reliable product that proves the Waypoint philosophy.

## MVP

### Explorer

-   Discover places
-   Maps
-   Navigation
-   Field Notes
-   Remember visits
-   Basic Passport

### Living Map

-   Places
-   Explorer Field Notes
-   Official Steward Notes
-   Temporary conditions

### Steward

-   Claim place
-   Manage place details
-   Welcome message
-   QR poster
-   Basic visitor insights

## Deferred

-   AI
-   Advanced analytics
-   Seasonal storytelling
-   Volunteer management
-   Marketplace
-   Recommendation engine
-   Regional management

## Scope Rules

Only include work that: 1. Supports the core vision. 2. Solves a genuine
user problem. 3. Does not materially delay release. 4. Is maintainable.

## Definition of Done

An explorer can discover, visit, remember and contribute.

A steward can maintain an accurate, welcoming place.

If both experiences are polished, Version 1 is ready to ship.
