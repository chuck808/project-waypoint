# WP200 -- Visual Language

## Design Inspiration

-   Ordnance Survey
-   National Trust
-   Field journals
-   Vintage guidebooks
-   British landscapes

## Visual Characteristics

-   Organic geometry
-   Rounded forms
-   Natural colour palette
-   Ink-inspired illustrations
-   Calm whitespace
-   Editorial typography

## Visual Hierarchy

1.  Landscape
2.  Story
3.  Content
4.  Controls

The interface should never become the focal point.

## Consistency

Every icon, illustration and component should appear as though created
by the same hand.
