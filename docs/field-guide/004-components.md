# Field Guide 004 – Components

This is not a complete component library.

It defines the component mood.

## Cards

Cards should feel like paper on a table.

- soft radius
- subtle shadow
- generous padding
- no heavy borders

## Buttons

Buttons should feel comfortable.

- rounded
- clear
- not glossy
- not urgent unless truly necessary

## Panels

Panels should group meaning, not fill space.

## Empty States

Empty states should reassure.

They should explain what happens next.
