# Field Guide 002 – Colours

Waypoint colours should feel discovered rather than invented.

One palette, one source of truth. These are the values shipped on every
surface; the names are the vocabulary. If a value changes here, it
changes everywhere.

## Core Palette

| Token | Hex | Use |
| --- | --- | --- |
| Cream | `#F7F3EA` | App and page backgrounds |
| Warm White | `#FFFDF7` | Raised surfaces, cards |
| Sage Soft | `#DDE8D5` | Gentle emphasis panels, pills |
| Sandstone | `#DDD3C2` | Hairline borders, dividers |
| Fern | `#3C5F46` | Primary actions, primary green |
| Moss | `#6D8265` | Secondary green, quiet accents |
| Slate | `#6B7261` | Secondary text, labels |
| Charcoal | `#2F3328` | Primary text |

## Stamp Inks

Ink colour is the category system. Inks appear only as stroke colour on
stamp marks — never as fills, backgrounds or UI chrome.

| Ink | Hex | Category |
| --- | --- | --- |
| Fern Ink | `#3C5F46` | Café |
| Umber | `#8A5A2B` | Pub |
| Olive | `#6B6B2A` | Farm shop |
| Tarn | `#3F5E6B` | Campsite |
| Heather | `#5A4A6B` | Outdoor shop |
| Bramble | `#7A3B4F` | Attraction |
| Bracken | `#4F5648` | Other |

## Rules

Use colour to guide. Do not use colour to shout.

Accents appear rarely; hierarchy comes from space and type first.
