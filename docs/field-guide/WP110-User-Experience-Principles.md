# WP110 -- User Experience Principles

## Experience before Interface

The interface should feel like a trusted companion rather than a
destination.

## Principles

### Calm

Whitespace is intentional.

### Confidence

The user should rarely wonder what happens next.

### Outdoor-first

Large touch targets, excellent sunlight contrast, offline resilience and
quick interactions.

### Progressive disclosure

Reveal complexity only when needed.

### Forgiving

Mistakes should be easy to recover from.

## Interaction Tone

The application should encourage, never pressure.

Avoid urgency where reassurance is possible.
