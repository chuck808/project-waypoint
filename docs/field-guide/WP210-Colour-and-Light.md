# WP210 -- Colour & Light

## Philosophy

Colour should support the landscape rather than compete with it.

## Core Palette

  Token     Purpose
  --------- ------------------
  Fern      Primary actions
  Moss      Success
  Heather   Secondary accent
  Stone     Surfaces
  Mist      Background
  River     Information
  Clay      Warning
  Ash       Neutral

## Rules

-   Use semantic names rather than hex values in design discussions.
-   Preserve WCAG AA contrast as a minimum.
-   Reserve vibrant colours for exceptional moments.

## Light & Dark

Dark mode should evoke dusk in the countryside, not high-contrast neon.

## Seasonal Variants

Allow subtle seasonal adjustments while preserving semantic meaning.
