# BP024 – Waypoint Design Library

**Status:** Draft

**Version:** 1.0

**Last Updated:** 2026-07-04

---

# Purpose

The purpose of this document is not to define a visual style.

It is to preserve a feeling.

Waypoint should feel recognisably like Waypoint whether someone is:

* using the mobile app
* printing a business invitation
* opening the Business Portal
* browsing the public website
* administering the platform

Consistency should come from shared principles rather than copied components.

---

# Design Philosophy

Waypoint is not a technology product wearing outdoor clothing.

Waypoint is an outdoor companion that happens to use technology.

Technology should quietly disappear behind the experience.

The interface should never compete with the walk.

---

# Emotional Keywords

Every design decision should move the interface towards these words:

* Calm
* Welcoming
* Honest
* Quiet
* Thoughtful
* Familiar
* Human
* Trustworthy
* Natural
* Unhurried

Not:

* Exciting
* Competitive
* Addictive
* Urgent
* Loud
* Flashy

---

# The Feeling

Imagine this scene.

You have just finished a walk.

Your boots are muddy.

You find a small independent café.

Someone smiles and says,

> "Come in."

That feeling is Waypoint.

Every screen should preserve it.

---

# Visual Language

Waypoint borrows its visual language from the British countryside rather than modern technology.

Think:

* Ordnance Survey maps
* National Trust cafés
* Village notice boards
* Wooden fingerposts
* Walking guidebooks
* Leather journals
* Paper maps
* Enamel mugs
* Dry stone walls
* Weathered timber

Not:

* Glassmorphism
* Neon gradients
* Gaming interfaces
* Cryptocurrency dashboards
* Trading platforms

---

# Colour

Colours should feel discovered rather than invented.

Primary palette:

* Moss
* Sage
* Fern
* Slate
* Charcoal
* Cream
* Sandstone
* Warm white

Accent colours should appear rarely.

Colour communicates hierarchy, not excitement.

---

# Typography

Typography should feel like reading.

Not watching.

Priorities:

* generous spacing
* calm rhythm
* comfortable line length
* understated hierarchy

Headings should feel like chapter titles.

Body copy should feel like a guidebook.

---

# Illustration

Illustration should be warm, simple and quietly charming.

Preferred subjects:

* boots
* mugs
* maps
* journals
* signposts
* hills
* trees
* walking sticks
* backpacks

Illustrations should support understanding rather than decorate empty space.

---

# Photography

Photography should celebrate real places.

Prefer:

* changing weather
* muddy paths
* cafés with character
* worn timber
* handwritten menus
* walkers resting
* local landscapes

Avoid:

* impossible sunsets
* empty perfection
* exaggerated adventure
* stock "influencer" imagery

Reality is beautiful enough.

---

# Iconography

Icons should feel like wayfinding symbols.

Simple.

Rounded.

Recognisable.

Avoid unnecessary detail.

The waypoint marker should become the primary visual symbol of the platform.

---

# Layout

Whitespace is a design material.

Interfaces should breathe.

Cards should be separated by space rather than borders.

Sections should feel like pauses in a walk.

Never make users feel rushed.

---

# Motion

Animation should reassure.

Not entertain.

Movement should explain change.

Animation should rarely exceed 250ms.

Nothing should bounce simply because it can.

---

# Writing

Waypoint speaks quietly.

Prefer:

> Welcome back.

Over:

> Great to see you!!

Prefer:

> Visit remembered.

Over:

> Success!

Prefer:

> Walking Mam Tor Circular

Over:

> ACTIVE SESSION

Write like a thoughtful walking companion.

Not a marketing department.

---

# Hospitality

Hospitality is the defining characteristic of Waypoint.

Businesses are not advertisements.

They are hosts.

Walkers are not customers.

They are guests.

Design should reinforce this relationship.

---

# Data

Numbers support stories.

Stories come first.

Prefer:

> 18 walkers remembered visiting this week.

Over:

> 18 Check-ins

Prefer:

> Returning walkers

Over:

> Repeat conversion rate

The platform measures activity.

The interface communicates meaning.

---

# Accessibility

Calm design should also be inclusive.

Every interface should consider:

* colour contrast
* readable typography
* keyboard navigation
* screen readers
* reduced motion
* generous touch targets

Accessibility is not an enhancement.

It is hospitality.

---

# Product Surfaces

Every Waypoint surface should feel related.

Mobile should feel personal.

The public website should feel inviting.

The Business Portal should feel appreciative.

The Admin Portal should feel trustworthy.

Different responsibilities.

One design language.

---

# Design Test

Before accepting any design, ask:

Does this feel like somewhere a walker would enjoy spending five quiet minutes after a good walk?

If the answer is no, redesign it.

---

# Design Constitution

Remember:

Technology supports the walk.

The walk creates the memory.

Local places enrich the walk.

Waypoint simply helps people remember.

Everything else is secondary.

---

# Summary

Waypoint should never feel like software competing for attention.

It should feel like a trusted companion that quietly waits until it is useful.

The best compliment a user could give the interface is:

> "It just feels right."

That is the design standard.
